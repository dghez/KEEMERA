Text the browser lays out, drawn on the GPU straight from quadratic Bézier outlines: sharp at any size, kerned and wrapped exactly like the DOM.

Justified · text-transform · sup

Nothing here is laid out twice. The browser breaks the lines, applies kerning and letter-spacing, justifies the block and sets E = mc2; a Range per character reads each pen position back. The GPU only rasterises: one instanced draw for every element of a font pack, so scrolling moves one transform and a re-measure happens only when an element’s size, text or font changes. Ligatures are off on tracked elements, so “fi” and “fl” draw the same glyphs as the DOM.
